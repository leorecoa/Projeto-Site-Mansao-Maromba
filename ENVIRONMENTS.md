## 🎯 Feature Flags (Optional)

### Using LaunchDarkly

**Install:**
```bash
npm install launchdarkly-react-client-sdk
```

**Setup:**
```typescript
// lib/featureFlags.ts
import { withLDProvider } from 'launchdarkly-react-client-sdk';

export const ldConfig = {
  clientSideID: import.meta.env.VITE_LAUNCHDARKLY_CLIENT_ID,
  context: {
    kind: 'user',
    key: 'anonymous'
  }
};

// Wrap App
export default withLDProvider(ldConfig)(App);
```

**Usage:**
```typescript
import { useFlags } from 'launchdarkly-react-client-sdk';

function Component() {
  const { newCheckoutFlow } = useFlags();
  
  return newCheckoutFlow ? <NewCheckout /> : <OldCheckout />;
}
```

## 🐛 Troubleshooting

### CI fails on type check
```bash
# Run locally
npx tsc --noEmit
```

### Preview deployment fails
- Check VERCEL_TOKEN is valid
- Verify project permissions
- Check build logs in Actions

### Production deployment fails
- Verify all secrets are set
- Check Supabase connection
- Review Vercel logs
